## AI analysis enrichment

Analyze returns a deterministic result first. When both `GEMINI_API_KEY` and `ANALYZE_ENCRYPTION_KEY` are configured, the Results page starts an optional evidence-enrichment pass. The resume/JD payload is encrypted temporarily, expires after 30 minutes, and is deleted after enrichment. If the key is not configured, the local analysis remains the supported fallback.

Set a strong random value for `ANALYZE_ENCRYPTION_KEY`; never commit it to source control.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
